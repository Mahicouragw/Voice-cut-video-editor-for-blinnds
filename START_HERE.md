# Start here — updated VoiceCut 2.0

For the requested one-command GitHub device authorization and deployment, run `npm run all` from this repository with GitHub CLI installed, then approve on GitHub. See [docs/GITHUB_DEVICE_DEPLOY.md](docs/GITHUB_DEVICE_DEPLOY.md).

Use [AI_UPDATE_START_HERE.md](AI_UPDATE_START_HERE.md) for the manual alternative: current code, patch selection and deployment steps.

The [API key guide](docs/API_KEYS_GUIDE.md) explains exactly how to create and place your caption keys (free Groq/Deepgram/AssemblyAI or paid OpenAI), ElevenLabs isolation key and separate server access key. The normal user interface has no key fields.

No permanent deployment or live paid provider verification has been performed here. See [the verification report](docs/REPAIR_REPORT.md) for remaining limitations.
